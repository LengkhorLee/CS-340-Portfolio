# CS-340-Portfolio
CS 340 Client/Server Development Portfolio
## Reflection

### Maintainable, Readable, and Adaptable Programs

I approach writing programs by keeping my code organized, readable, and separated into components that have specific responsibilities. In this project, the CRUD Python module was responsible for communicating with the MongoDB database, while the dashboard code used the module to retrieve the information it needed. One advantage of working this way was that I did not have to rewrite the database connection and CRUD operations throughout the dashboard. The same module could also be reused or modified for another application that needs to work with MongoDB in the future.

### My Approach as a Computer Scientist

I approached the database and dashboard requirements by breaking the project into smaller parts and testing each part as I worked. I first made sure the database connection and CRUD operations worked correctly before connecting them to the dashboard. I then worked on displaying and filtering the data based on the requirements from Grazioso Salvare. This project was different from some of my previous assignments because several components had to work together, including Python, MongoDB, and the interactive dashboard. In future projects, I would continue breaking larger requirements into smaller tasks and testing each component before combining everything.

### What Computer Scientists Do and Why It Matters

Computer scientists use technology and problem-solving skills to create systems that organize information, automate tasks, and help people make decisions. This type of work matters because software can turn large amounts of data into information that is easier to understand and use. For a company such as Grazioso Salvare, the dashboard makes it easier to search and filter animal shelter data and identify animals that may meet specific rescue requirements. This can save time and help the organization make better use of its data.
